# Заметки на будущее

Мелкие улучшения и технический долг, замеченные при реализации и ревью спек. Решения человека не требуют, работу не блокируют: это то, что стоит сделать, когда будем трогать соответствующее место. Вопросы, где нужен выбор, — в [questions.md](questions.md), а не здесь.

Формат: `N-n` — номер по порядку, не переиспользуется. Где — файл или область. Когда — момент, когда заметку взять в работу (спека из [реестра](README.md#реестр-спек) или событие: «при добавлении нового пакета»). 

Жизненный цикл: при черновике каждой новой спеки `/write-spec` забирает отсюда заметки, которые можно сделать в её области, превращает их в задачи `T-k` со ссылкой «из N-n» и удаляет отсюда. Здесь остаётся только то, до чего ещё не дошли ([процесс](README.md#цикл-работы-со-спекой)).
