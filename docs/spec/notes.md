# Заметки на будущее

Мелкие улучшения и технический долг, замеченные при реализации и ревью спек. Решения человека не требуют, работу не блокируют: это то, что стоит сделать, когда будем трогать соответствующее место. Вопросы, где нужен выбор, — в [questions.md](questions.md), а не здесь.

Формат: `N-n` — номер по порядку, не переиспользуется. Где — файл или область. Когда — момент, когда заметку взять в работу (спека из [реестра](README.md#реестр-спек) или событие: «при добавлении нового пакета»). 

Жизненный цикл: при черновике каждой новой спеки `/write-spec` забирает отсюда заметки, которые можно сделать в её области, превращает их в задачи `T-k` со ссылкой «из N-n» и удаляет отсюда. Здесь остаётся только то, до чего ещё не дошли ([процесс](README.md#цикл-работы-со-спекой)).

## Открытые

- [ ] **N-2. Версия npm — диапазон, а не точная.** *(из ревью 000; где — корневой `package.json`, `engines.npm`; когда — если появятся расхождения `package-lock.json` между машинами; Claude, 2026-10-21)*
  REQ-000-3 требует зафиксировать версии, а стоит `"npm": ">=11.0.0"`. Для разработки хватает, но разные мажорные npm могут по-разному писать lock-файл. Вариант: поле `packageManager` с точной версией и `engines.npm` в узком диапазоне.

- [ ] **N-4. Сверить решения 001 с актуальной документацией через context7.** *(из обсуждения реализации 001; где — пакеты, созданные и изменённые в 001: `apps/ui/cabinet`, `adapter-docker`, `adapter-nats`, `adapter-memory`, `adapter-orchestrator-http`, `api-integration`, `ui-core`, оболочки `api`, `orchestrator`, `agent`, `compose.yaml`, Dockerfile; когда — спека 002; Claude, 2026-10-22)*
  001 реализован без context7 (MCP не был подключён), API библиотек могли взять по памяти модели. Подключить context7 и по его документации проверить: версии и рекомендуемые API Angular (standalone, signals, `ng serve` с прокси для WebSocket), dockerode, `@nats-io/transport-node`, Fastify (WebSocket), Docker Compose. Устаревшее или нерекомендуемое — исправить задачами 002, решения записать в README пакетов.

- [ ] **N-5. vitest подхватывает тесты из `.claude/worktrees/**`.** *(из реализации 016; где — `vitest.config.ts`, `exclude`; когда — при следующей правке конфигурации тестов или раньше, если мешает локально; Claude, 2026-10-22)*
  `include: ['**/*.test.ts']` находит тесты git worktree-ов агентов в `.claude/worktrees/`. Локально `npm test` гоняет их вместе с основными, и тесты с общими ресурсами (Docker-контейнеры с одинаковыми метками в AC-001-22, AC-016-10) мешают друг другу. В CI worktree-ов нет. Сделать: добавить `'.claude/**'` в `exclude`. До правки локально запускать `npx vitest run --exclude ".claude/**"`.

- [ ] **N-6. Запуск UI на хосте с горячей перезагрузкой.** *(из обсуждения dev-режима; где — `apps/ui/cabinet/proxy.conf.json`; когда — спека 014 или раньше, если пересборка образа `ui` на каждую правку начнёт мешать; Claude, 2026-10-22)*
  В `npm run dev` watch для `ui` нет: исходники копируются в образ при сборке, правка видна только после `docker compose up -d --build ui`. UI можно запускать на хосте (`npm start -w apps/ui/cabinet`) и получить горячую перезагрузку, но `proxy.conf.json` ведёт на `api:3000` и `lgtm:3000` — имена сети compose, с хоста они не открываются. Сделать: отдельный конфиг прокси на `127.0.0.1` (`API_PORT`, `GRAFANA_PORT`) и команду запуска с ним.
