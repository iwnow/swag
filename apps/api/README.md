# @swag/api

Оболочка ядра `@swag/api-core`: HTTP API платформы на Fastify. Через него UI и внешние клиенты работают с роями, планами и расходами.

## Задачи

- Принимает HTTP-запросы, вызывает операции `api-core`, отдаёт результат в JSON.
- Читает конфигурацию из env (`ApiConfig` из `@swag/config`) и собирает адаптеры для ядра.
- Отдаёт `GET /health` для healthcheck в compose.

## Что внутри сейчас

Заглушка из спеки 000: `GET /health` → `{"status":"ok","service":"api","version":"…"}`. Версию берёт из своего `package.json` и передаёт ядру.

- `src/main.ts` — точка входа: конфигурация, ядро, запуск сервера, остановка по `SIGINT`/`SIGTERM`.
- `src/app.ts` — `buildApp(core)`: Fastify-приложение и маршруты. Тесты вызывают его через `inject` без сети и Docker.

## Ограничения

- Никакой логики предметной области: только разбор запроса, вызов ядра, формирование ответа. Всё остальное — в `api-core` ([архитектура](../../docs/architecture.md)).
- Слушает `0.0.0.0` внутри контейнера; наружу порт `API_PORT` публикуется только на `127.0.0.1`.
- Запускается из исходников через type stripping Node 24, без сборки.

## Связи

- Использует: `@swag/api-core`, `@swag/config`, `fastify`.
- Запуск: сервис `api` в [compose.yaml](../../compose.yaml).

## Спеки

- 000 — заглушка с `/health`.
- 001, 003, 009, 010, 012, 013 — события и расходы, LiteLLM, план роя, API для UI, проверка токена и доступа, баланс (`billing-core` в этом процессе) ([реестр](../../docs/spec/README.md#реестр-спек)).
