# apps/ui

Оболочка пользовательского приложения: веб-интерфейс, в котором пользователь ставит задачу, видит граф роя и сколько тратится денег.

## Задачи

- Показывает рои, агентов, переписку по шине и расходы в реальном времени — по рою, агенту и шагу.
- Даёт поставить задачу, посмотреть и утвердить план роя.
- Вся логика экрана (вход, права, балансы, проекты, рои) — в ядре `packages/ui-core`, оболочка только рисует и передаёт действия пользователя.

## Что внутри сейчас

Только этот README. Приложение и ядро `ui-core` появятся в спеке 010.

## Ограничения

- Фреймворк — Angular, но `ui-core` от него не зависит: поверх того же ядра можно сделать оболочку на другом фреймворке ([архитектура](../../docs/architecture.md)).
- С платформой работает только через HTTP API `apps/api`.
