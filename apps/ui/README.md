# apps/ui

Папка фронтендов платформы — всего, что видит человек. Сама папка не пакет: каждый фронтенд внутри — отдельный пакет (npm workspaces `apps/ui/*`), который собирается и деплоится независимо от остальных и может быть на своей технологии.

## Задачи

- Показывают рои, агентов, переписку по шине и расходы в реальном времени — по рою, агенту и шагу.
- Дают поставить задачу, посмотреть и утвердить план роя.
- Дают администратору организации и супервизору управлять пользователями, балансами, ценами и лимитами.
- Вся логика экранов (вход, права, баланс, рои, админка) — в ядре `packages/ui-core`, фронтенды только рисуют и передают действия пользователя.

## Что внутри сейчас

Только этот README. `cabinet` и ядро `ui-core` появятся в спеке 001, в ней `cabinet` — самостоятельное приложение; каркас и микрофронтенды — в 014.

## Ограничения

- `ui-core` не зависит от фреймворка: поверх того же ядра можно сделать фронтенд на другой технологии ([архитектура](../../docs/architecture.md)).
- С платформой фронтенды работают только через HTTP API `apps/api` (вход — через `apps/identity` с 012).
- Защита данных — на сервере: скрытая кнопка или неподгруженный микрофронтенд доступа не ограничивают.
- Способ сборки микрофронтендов и деление `ui-core` по фронтендам — D-11 ([questions.md](../../docs/spec/questions.md)).

## Спеки

- 001 — `cabinet`: создание роя с ролями, живая лента и граф; 004 — панель денег; 014 — каркас с входом, админка организации, супервизор ([реестр](../../docs/spec/README.md#реестр-спек)).
