# @swag/cabinet

Личный кабинет (Angular). В 001 — самостоятельное приложение с экранами роя; в 014 станет микрофронтендом каркаса.

## Задачи

- `/` — список роёв: задача, статус, число агентов, время; кнопка «Новый рой».
- `/swarms/new` — форма: задача, «Бюджет, $» роя (по умолчанию `0.50`, шаг `0.01`) и агенты (имя, роль, модель из `PlatformModel`, по умолчанию `chat-small`, «Бюджет агента, $» — необязательный, пустое поле — бюджета нет). Первый агент — вход: получает задачу и завершает рой через `finish` (спека 022). Бюджеты переводятся в micro-USD через `usdToMicro` (спека 004, 4.8).
- `/swarms/:id` — строка денег над графом (потрачено из бюджета, остаток, расход за последнюю минуту — `formatSwarmMoney` и `spentLastMinute`; обновляется по каждому событию и раз в 5 с), граф (агенты по кругу, цвет по статусу, модель и число шагов в узле, на рёбрах стрелка и число сообщений), список агентов с суммой «потрачено» и бюджетом, если он задан (`formatUsd`), лента событий, результат или причина ошибки (`budget_exceeded` — «бюджет исчерпан», `gateway_unavailable` — «шлюз моделей недоступен», `detail` рядом), «Стоп» для активного роя. Обновление — из WebSocket. У события с `traceId` в ленте — ссылка «Трейс» в новой вкладке (спека 016). Событие `llm.call` выводится строкой вызова модели через `formatLlmCall` из `@swag/ui-core` (спека 002, 4.11), `agent.step` — строкой шага через `formatAgentStep` (спека 022, 4.10). `agent.idle` в ленте без особого формата — пустое описание, как у прочих событий без строки. `bus.message`, которое получатель не начал обрабатывать, помечается «не прочитано» (спека 030, REQ-030-6): вычисляет `unreadMessageIds` из `@swag/ui-core` по ленте и статусу роя, компонент только выводит отметку классом `unread`.

## Что внутри сейчас

- `src/app/api.ts` — адаптеры портов `ui-core`: REST и WebSocket по относительному пути `/api`.
- `src/app/ui.ts` — `ui-core` в DI-токене `UI`; `TRACE_URL_TEMPLATE` — шаблон ссылки на трейс в Grafana Explore.
- `src/app/swarm-graph.ts` — граф роя, чистый SVG без библиотеки (Q-4). Геометрия — чистые функции `layoutNodes` (узлы по кругу) и `edgePath` (путь ребра, дуга, петля).
- Страницы: `swarm-list.page.ts`, `swarm-new.page.ts`, `swarm.page.ts`.
- `src/app/money.ts` — перевод полей формы в вход `createSwarm` (`swarmFormInput`, `agentBudgetMicro`) и тексты причин `swarm.failed` (`failureReasonText`).
- `test/money.test.ts` — тесты `money.ts` (перевод бюджетов, проверка через `SwarmCreateRequest`, тексты причин).
- `proxy.conf.json` — `/api` → `api:3000` (снимает префикс; WebSocket включён); `/grafana` → `lgtm:3000` без снятия префикса (Grafana на подпути).
- `Dockerfile` — dev-образ для `npm run up` (`ng serve`).

## Ограничения

- Только `ng serve` (Q-4). Скрипт `build` (`ng build`) в `package.json` есть, но в CI и в Docker-образе не используется; раздачи собранного приложения в 001 нет.
- Компоненты не содержат правил: валидация, состояние роя и переподключение — в `@swag/ui-core`.
- Пользовательский текст выводится только интерполяцией Angular, без `innerHTML`.
- Входа нет (до спеки 012).
- Тесты только у `money.ts`: компоненты проверяются сборкой `ng build` и ручным прогоном, Angular-тестового раннера в проекте нет. Запуск: `node node_modules/vitest/vitest.mjs run apps/ui/cabinet`.
- Превышение бюджета агента над бюджетом роя форма не проверяет: `SwarmCreateRequest` этого не требует, сервер отвечает `400`, текст выводится в ошибке формы (спека 004, 4.7, D-105).

## Связи

- Логика: `@swag/ui-core`; типы и проекция: `@swag/contracts`, `@swag/api-integration`.
- Бэкенд: `apps/api` через прокси.

## Ключевые решения

- Angular 22.2.3 (`@angular/*`, `@angular/build`, `@angular/cli`), состояние — signals. Версии точные (`save-exact`). Zoneless — по умолчанию с Angular 21 (angular.dev/guide/zoneless), отдельного провайдера в `app.config.ts` нет.
- `proxy.conf.json` подключён через `angular.json` → `serve.options.proxyConfig`. `ws: true` передаётся в прокси Vite, `pathRewrite` `@angular/build` переводит в `rewrite` (`utils/load-proxy-config.js`). angular.dev (https://angular.dev/tools/cli/serve) описывает только `target` и `secure`; поведение `ws`/`pathRewrite` — по исходникам установленного `@angular/build` 22.2.3. `provideBrowserGlobalErrorListeners` есть в типах `@angular/core`.
- Граф — собственный SVG-компонент без библиотеки (Q-4). Узлы по кругу в порядке id, радиус не меньше 120 px и не меньше, чем нужно для зазора `NODE_GAP` между соседними узлами. Встречные рёбра `a → b` и `b → a` рисуются квадратичными кривыми внутрь круга на разную глубину (15 и 60 px), подписи пары — ближе к началу своей дуги, поэтому не накладываются. Наружу дуга не выгибается: при 5 и более агентах она заходила бы под соседний узел (ревью T-15); параметры проверены расчётом для 2–8 агентов; одиночное ребро — прямая. Петля (ребро на себя, по 4.10) — дуга наружу от круга. Подписи с белой обводкой, чтобы читались на линии.
- Шаги агента (`agent.step`) — строкой ленты через `formatAgentStep`, без отдельного экрана.
- Деньги (спека 004, 4.8): доллары переводит `usdToMicro` из `ui-core`, пустой бюджет агента — `null`, некорректный ввод даёт `NaN`, который отсекает `SwarmCreateRequest`. Все суммы на экране — через `formatUsd` и `formatSwarmMoney`; компонент только собирает строки.
- Строка денег обновляется таймером раз в 5 с (`MONEY_TICK_MS` в `swarm.page.ts`) и по каждому событию. Таймер запускается в конструкторе страницы и очищается в `ngOnDestroy`, поэтому на другой странице не работает. Таймер ui-core (`Timers`) для него не используется: он нужен только для переподключения потока.
- Тексты причин `budget_exceeded` и `gateway_unavailable` — из 4.8, прочие причины выводятся как пришли (D-107).
- Логика вне компонентов: `createUiCore` из `@swag/ui-core` подключается через токен `UI`.
- Dev-сервер и прокси `/api` → `api:3000` (Q-4). Отклонение: в CI сборка `ng build` не запускается (спека требует `npm run check` без UI-шага).
- `allowImportingTsExtensions` и `rewriteRelativeImportExtensions` в tsconfig — чтобы Angular собирал TS-исходники `packages/*` с расширениями `.ts`.
- Ссылка «Трейс» (016, Q-6): относительный адрес `/grafana/explore?...` через прокси `ng serve`, без конфигурации в UI. Шаблон — Explore Grafana с источником Tempo (uid `tempo` в `grafana/otel-lgtm`), запрос TraceQL — сам `traceId`, диапазон — последние 7 дней. Адрес строит `ui-core.traceUrl`, компонент только рисует `<a target="_blank" rel="noopener">`. SDK OpenTelemetry в браузере нет (Q-7).
