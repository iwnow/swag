# @swag/agent

Оболочка ядра `@swag/agent-core`: процесс, который работает внутри песочницы и выполняет одного агента роя.

## Задачи

- Запускается в песочнице, получает от оркестратора роль, модель, скиллы и лимиты агента.
- Собирает для ядра адаптеры: клиент LiteLLM (виртуальный ключ агента), шина NATS роя, рабочая папка `/work`, выполнение инструментов.
- Передаёт управление агентному циклу в `agent-core` и завершается, когда цикл закончен или исчерпан бюджет.

## Что внутри сейчас

Заглушка из спеки 000: печатает версию Node, версию агента и `agent ok`, выход 0.

- `src/main.ts` — точка входа.
- `src/run.ts` — `runAgent(version, print)`: вызов ядра и вывод, тестируется без Docker.
- `Dockerfile` — образ `swag-agent:dev`.

## Ограничения

- Образ не стартует в `npm run up`: собирается `docker compose build agent`, запускается `docker run --rm swag-agent:dev`. В рабочем режиме его запускает оркестратор.
- В песочнице нет ключей провайдеров моделей — только виртуальный ключ LiteLLM с бюджетом. Выход в интернет закрыт, доступны только LiteLLM и шина своего роя.
- Песочница одноразовая: состояние, которое нужно сохранить, уходит в Postgres, S3 и NATS, а не остаётся в процессе.
- Время холодного старта важно для роя; точка отсчёта — замер NFR-000-3 в журнале спеки 000 (медиана до `agent ok` около 300 мс).

## Связи

- Использует: `@swag/agent-core`.
- Запуск: сервис `agent` с `profiles: [agent]` в [compose.yaml](../../compose.yaml); позже — оркестратор через `SandboxProvider`.

## Спеки

- 000 — заглушка и образ.
- 004, 006, 007, 008 — песочница, агентный цикл, скиллы, шина ([реестр](../../docs/spec/README.md#реестр-спек)).
