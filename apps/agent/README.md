# apps/agent

Оболочка агента: процесс в песочнице. Подключает `agent-core` к NATS и печатает баннер запуска.

## Задачи

- Прочитать `AgentConfig` из env, подписаться на свой inbox, опубликовать `agent.started`, выполнять эстафету (спека 001, 4.7).
- По `SIGTERM` закрыть соединение с NATS и выйти с кодом 0 (REQ-001-17).

## Что внутри сейчас

- `src/run.ts` — баннер: версия Node, версия агента, `agent ok`.
- `src/main.ts` — конфигурация, адаптер NATS, ядро, запуск, обработка `SIGTERM`.
- Тесты: `test/run.test.ts` (AC-000-13 — баннер).

## Ограничения

- Агент без LLM и инструментов (спека 002).
- Токен пользователя и доступ к данным платформы в песочнице не нужны и не передаются.

## Связи

- Ядро: `@swag/agent-core`. Адаптер: `@swag/adapter-nats`. Конфигурация: `@swag/config`.

## Ключевые решения

- Баннер `node/agent/agent ok` печатается до подключения к NATS: это старт процесса, а не готовность эстафеты (AC-000-13 сохранён).
- Образ агента `apps/agent/Dockerfile` собирается отдельно (`npm run agent:image`, профиль `agent`) и не стартует в `npm run up`.
- `SIGTERM` → `drain` NATS → `exit(0)` (REQ-001-17).

## Спеки

- 000 — заглушка. 001 — 4.7.
