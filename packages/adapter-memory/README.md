# @swag/adapter-memory

Адаптер порта `SwarmStore` из `api-core` в памяти процесса. Хранит события роя и `SwarmView`, которые строятся через `applyEvent` из `api-integration`.

## Задачи

- Реализовать `SwarmStore` (спека 001, 4.5.4) без базы данных. Роёв и событий после перезапуска `api` нет — это ожидаемо до спеки 003.

## Что внутри сейчас

- `createMemorySwarmStore()` — `appendEvent`, `events`, `view`, `views`.

## Ограничения

- Теряет все данные при перезапуске процесса.
- Повторный `seq` игнорируется без ошибки; недопустимое событие бросает исключение и не сохраняется.

## Связи

- Порт: `SwarmStore` из `@swag/api-core` (только типы).
- Использует: `@swag/api-integration`, `@swag/contracts`.
- Оболочка: `apps/api`.

## Ключевые решения

- Один объект на роя: события (`PlatformEvent[]`) и `SwarmView` хранятся рядом, `SwarmView` обновляется через `applyEvent` при каждом `appendEvent` (T-9).
- Памяти не нужны блокировки: все операции синхронны внутри процесса `api`.

## Спеки

- 001 — REQ-001-3. Замена на Postgres — спека 003, без правки `api-core`.
