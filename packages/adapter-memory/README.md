# @swag/adapter-memory

Адаптер порта `SwarmStore` из `api-core` в памяти процесса. Хранит события роя и `SwarmView`, которые строятся через `applyEvent` из `api-integration`.

## Задачи

- Реализовать асинхронный `SwarmStore` (спека 003, REQ-003-10) без базы данных — для тестов ядра и оболочки.
- Рабочее хранилище роёв — `@swag/adapter-postgres` (спека 003, T-5, T-6); этот адаптер в `apps/api` больше не используется.

## Что внутри сейчас

- `createMemorySwarmStore()` — `appendEvent`, `events`, `view`, `views`; все методы `async`.

## Ограничения

- Теряет все данные при перезапуске процесса.
- Повторный `seq` игнорируется без ошибки; недопустимое событие — reject, ничего не сохраняется.
- Не потокобезопасен сверх одного процесса; очередь записи роя — в `api-core`, не здесь.

## Связи

- Порт: `SwarmStore` из `@swag/api-core` (только типы).
- Использует: `@swag/api-integration`, `@swag/contracts`.
- Потребители: тесты `packages/api-core` и `apps/api`.

## Ключевые решения

- Один объект на роя: события (`PlatformEvent[]`) и `SwarmView` хранятся рядом, `SwarmView` обновляется через `applyEvent` при каждом `appendEvent`.
- Методы асинхронные (003, Q-1), хотя работают синхронно внутри: так один порт проверяется тестами ядра и совпадает с Postgres-адаптером.

## Спеки

- 001 — REQ-001-3, 4.10 (исходная реализация в памяти).
- 003 — REQ-003-10: тот же асинхронный порт, остаётся для тестов ядра.
