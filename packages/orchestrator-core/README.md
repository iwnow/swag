# @swag/orchestrator-core

Ядро оркестратора: алгоритмы исполнения плана роя. Чистый TypeScript, не знает про Docker, NATS и Fastify — работает с ними через порты.

## Задачи

- Исполнить проверенный план роя детерминированно: песочницы, сеть роя, виртуальные ключи, account шины — в правильном порядке, с откатом при ошибке.
- Тёплый пул песочниц: сколько держать, когда пополнять.
- Учёт compute-расходов (время песочницы × тариф) в ledger.
- Уборка (reaper): освободить ресурсы роя по завершении или по TTL.
- Снимки рабочей папки на границе шага и возобновление агента.

## Что внутри сейчас

Заглушка из спеки 000: фабрика `createOrchestratorCore({ version })` и операция `info()`, возвращающая `ServiceInfo`.

## Ограничения

Правила ядра ([архитектура](../../docs/architecture.md), [спека 000, 4.2](../../docs/spec/000-foundation.md#42-правила-ядра-и-оболочки)):

- Зависимости — только `zod` и `@swag/contracts`.
- Нет Node API, `process`, env, файлов, сети: `tsconfig` без `@types/node` и DOM.
- Инфраструктура — только через порты ядра: `SandboxProvider` (Docker, позже microVM), шина, ключи LiteLLM, хранилища. Реализации — адаптеры `packages/adapter-<технология>`, их передаёт оболочка.
- Без глобального состояния: каждый вызов фабрики — независимое ядро.

Нарушения ловят `npm run arch:check` и `npm run typecheck`.

## Связи

- Оболочка: `apps/orchestrator`.
- Использует: `@swag/contracts`.
