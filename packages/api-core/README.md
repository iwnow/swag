# @swag/api-core

Ядро API платформы: логика, с которой работает пользователь через `apps/api`. Чистый TypeScript, не знает про HTTP и Fastify.

## Задачи

- Координатор: по задаче пользователя получить от LLM план роя (`SwarmPlan`) и проверить его.
- Рои и планы: создание, утверждение пользователем, передача на исполнение оркестратору, статусы.
- Расходы: сколько потрачено по рою, агенту и шагу, бюджеты.
- Доступ: операции с данными пользователя принимают `Actor` и отклоняют чужое; пользователь видит свои рои, администратор — все (спека 012, [архитектура](../../docs/architecture.md#доступ-кто-вызывает-ядро)).
- Пользователи, вход и роли — не здесь, а в `identity-core`; баланс — в `billing-core` (спеки 012, 013).

## Что внутри сейчас

Заглушка из спеки 000: фабрика `createApiCore({ version })` и операция `info()`, возвращающая `ServiceInfo`.

## Ограничения

Правила ядра ([архитектура](../../docs/architecture.md), [спека 000, 4.2](../../docs/spec/000-foundation.md#42-правила-ядра-и-оболочки)):

- Зависимости — только `zod` и `@swag/contracts`.
- Нет Node API, `process`, env, файлов, сети: `tsconfig` без `@types/node` и DOM.
- Всё внешнее — через порты, которые объявляет ядро; реализации передаёт оболочка в фабрику.
- Без глобального состояния: каждый вызов фабрики — независимое ядро.

Нарушения ловят `npm run arch:check` и `npm run typecheck`.

## Связи

- Оболочка: `apps/api`.
- Использует: `@swag/contracts`.

## Спеки

- 000 — заглушка.
- 001, 002, 003, 004, 009 — рои и события, результат роя, хранение, расходы из LiteLLM, координатор и план роя ([реестр](../../docs/spec/README.md#реестр-спек)).
