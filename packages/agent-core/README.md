# @swag/agent-core

Ядро агента: агентный цикл «вызов модели → вызовы инструментов → результаты». Чистый TypeScript, не знает, где запущен — в песочнице, в тесте или в eval-прогоне.

## Задачи

- Агентный цикл на OpenAI-формате с четырьмя сценариями ответа модели: только текст; один `tool_call`; параллельные `tool_calls`; текст и `tool_calls`.
- Журнал инструментов: запись `started` и результата по `tool_call_id`, возобновление после перезапуска песочницы без повторного выполнения неидемпотентных действий.
- Скиллы: подключение по `activate_skill` без инвалидации кэша промпта.
- Обмен сообщениями с другими агентами роя, лимиты шагов и бюджета.

## Что внутри сейчас

Заглушка из спеки 000: фабрика `createAgentCore({ version })` и операция `info()`, возвращающая `ServiceInfo`.

## Ограничения

Правила ядра ([архитектура](../../docs/architecture.md), [спека 000, 4.2](../../docs/spec/000-foundation.md#42-правила-ядра-и-оболочки)):

- Зависимости — только `zod` и `@swag/contracts`. Даже клиент модели (OpenAI SDK) — адаптер за портом, а не зависимость ядра.
- Нет Node API, `process`, env, файлов, сети: `tsconfig` без `@types/node` и DOM.
- Модель, шина, файлы `/work`, инструменты — только через порты; реализации передаёт оболочка `apps/agent`.
- Ключи провайдеров моделей ядро никогда не видит.

Нарушения ловят `npm run arch:check` и `npm run typecheck`.

## Связи

- Оболочка: `apps/agent`.
- Использует: `@swag/contracts`.
